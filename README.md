# Proje Hakkında

Projenin adı: "mini_catalog".

Hazırlayan: İsmail Koçyiğit


Bu proje bir e-ticaret sitesinin giriş, ürün listesi (kataloğu), ürün detayları ve sepet sayfalarından oluşmatadır.

Projenin teknik özellileri:
- Sayfa geçişleri (Navigator)
- Route Arguments kullanımı
- GridView ile kart tabanlı tasarım
- State güncelleme
- Asset yönetimi (görseller, JSON)

Ürün bilgileri "https://wantapi.com/products.php" web adresinden alınmaktadır.

Kullanılan Flutter sürümü: 3.13.5

# Çalıştırma Adımları

Proje indirildikten sonra, dosya adresinde terminal açılmalı ve aşağıdaki kodlar çaıştırılmalıdır:

Gereksinimleri kurmak için:

```bash
flutter pub get
```

Gereksinimler kurulduktan sonra projeyi çalıştırmak için:

```bash
flutter run
```

veya

seçilen IDE programı içinde, "main.dart" dosyası içindeki, "main()" fonksiyon çalıştırılabilir.
